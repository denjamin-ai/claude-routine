### 1. [New Microsoft tool lets devs spin up AI behavior tests using text descriptions](https://techcrunch.com/2026/06/02/new-microsoft-tool-lets-devs-spin-up-ai-behavior-tests-using-text-descriptions/) — 8.0
**Источник:** TechCrunch · **дата:** 2026-06-02

**Почему важно.** Высокие R и N: новый инструмент в самом центре темы AI-тестирования, анонсирован на Build 2026 — значимое событие. Практическая польза велика для QA AI-агентов, чуть сдерживает нишевость (пока применимо преимущественно к AI-системам, не классическим автотестам) и то, что источник — TechCrunch, а не Microsoft DevBlog напрямую.

Microsoft представил ASSERT (Adaptive Spec-driven Scoring for Evaluation and Regression Testing) — MIT-лицензированный open-source фреймворк, превращающий plain-text описание политик AI-агентов в исполняемые scored-тесты. Анонсирован на Microsoft Build 2026, поддерживает LangChain, CrewAI, OpenAI и другие фреймворки.
