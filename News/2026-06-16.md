### 1. [Playwright v1.61.0 Released](https://github.com/microsoft/playwright/releases/tag/v1.61.0) — 9.4

**Источник:** GitHub · **дата:** 2026-06-15

**Почему важно.** Мажорный минорный релиз ключевого e2e-фреймворка от официального репозитория; WebAuthn Passkeys и Web Storage API — практически применимые прямо сейчас новые возможности для SDET. Балл чуть сдерживает инкрементальность (не мажор).

Вышел Playwright 1.61.0: добавлен виртуальный аутентификатор WebAuthn Passkeys (тест без реального железа), новый Web Storage API (localStorage/sessionStorage), расширенные режимы записи видео и поддержка expect.soft.poll(). Прямое влияние на e2e-тесты: проще тестировать passkey-сценарии и управлять хранилищем браузера.

### 2. [pytest 9.1.0 Released](https://github.com/pytest-dev/pytest/releases) — 9.1

**Источник:** GitHub · **дата:** 2026-06-13

**Почему важно.** Центральный Python-тест-фреймворк, официальный источник; register_fixture() и --max-warnings дают сразу применимые механики для улучшения тест-сьютов. Чуть ниже Playwright из-за большей давности (3 дня) и меньшей яркости фич.

Вышел pytest 9.1.0: добавлен pytest.register_fixture() для программной регистрации фикстур, флаг --max-warnings для контроля числа предупреждений, поддержка datetime/timedelta в pytest.approx и официальная поддержка Python 3.15. Затрагивает всю Python-экосистему тестирования.

### 3. [GitHub Agentic Workflows is now in public preview](https://github.blog/changelog/2026-06-11-github-agentic-workflows-is-now-in-public-preview/) — 8.1

**Источник:** GitHub Blog · **дата:** 2026-06-11

**Почему важно.** Значимая новинка в парадигме AI+CI от авторитетного источника; анализ CI-сбоев и мониторинг тест-покрытия — прямой SDET-юзкейс, но тематика чуть шире чистого тест-тулинга, что снижает R. Свежесть умеренная (5 дней).

GitHub Agentic Workflows вышел в публичный превью: AI-агенты внутри GitHub Actions автоматизируют анализ CI-сбоев, мониторинг тестового покрытия, триаж ишью и обновление документации — задачи задаются в формате Markdown и компилируются в стандартный Actions YAML. Прямое применение для автоматизации QA-процессов в CI/CD.

### 4. [New runner images in public preview — GitHub Actions](https://github.blog/changelog/2026-06-11-new-runner-images-in-public-preview/) — 7.3

**Источник:** GitHub Blog · **дата:** 2026-06-11

**Почему важно.** Полезная инфраструктурная новость для CI тестовых пайплайнов, официальный источник; практическая польза умеренная (нужно обновить конфиги), новизна невысокая — это образ, а не фича. Снижает балл низкая N и умеренная свежесть.

GitHub Actions получил два новых образа раннеров в публичном превью: Ubuntu 26.04 (x64 и arm64) и Windows 11 arm64 с Visual Studio 2026. Позволяет запускать тестовые пайплайны на актуальных ОС и архитектурах без настройки собственных раннеров.
