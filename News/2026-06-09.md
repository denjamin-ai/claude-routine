### 1. [Control which k6 version runs your Synthetic Monitoring checks](https://grafana.com/whats-new/2026-06-03-control-which-k6-version-runs-your-synthetic-monitoring-checks/) — 7.7
**Источник:** grafana.com · **дата:** 2026-06-03

**Почему важно.** Полезная фича для k6-пользователей Grafana Cloud: решает реальную боль плавного перехода между мажорными версиями без риска поломки продовых проверок; высокий P и N благодаря новому механизму версионирования, балл чуть снижает свежесть (6 дней) и более узкая аудитория (только Grafana Cloud).

Grafana Cloud Synthetic Monitoring получил поддержку k6 version channels: теперь можно явно выбирать, на какой мажорной ветке (v1.x или v2.x) запускаются scripted- и browser-проверки, и мигрировать постепенно. Полезно для команд, использующих Grafana Cloud для мониторинга через k6-скрипты.

### 5. [GitHub Actions windows-latest Moves to VS 2026 Today](https://byteiota.com/github-actions-windows-vs2026-migration/) — 6.8
**Источник:** byteiota.com · **дата:** 2026-06-08

**Почему важно.** Операционно важная новость для Windows-пайплайнов — потенциально ломает тесты, обходной путь практичен; балл снижает вторичность источника (byteiota, а не официальный GitHub Changelog) и смежность тематики (CI-инфраструктура, а не тест-фреймворк напрямую).

Начиная с 8 июня windows-latest и windows-2025 в GitHub Actions переключаются на Visual Studio 2026 по умолчанию. Часть проектов сломала CI/CD, в том числе тестовые пайплайны с Node.js и Windows 10 SDK; обходной путь — явно указать windows-2022.
