### 1. [Playwright 1.64.0](https://github.com/microsoft/playwright/releases) — 8.9
**Источник:** GitHub · **дата:** 2026-10-07

**Почему важно.** Релиз ядрового e2e-фреймворка от первоисточника с фичами, применимыми сразу (shuffle, within, WebMCP); снижает балл наличие breaking changes.

Playwright 1.64.0: поддержка WebMCP (`page.webmcp` — вызов инструментов, зарегистрированных страницей для AI-агентов), `locator.within()`, флаг `--shuffle` для случайного порядка тестов, кастомный fps и VP9 для видео. Есть breaking changes: `screen` в эмуляции устройств и скрытые iframe.

### 2. [Selenium 4.51.0](https://github.com/SeleniumHQ/selenium/releases) — 7.6
**Источник:** GitHub · **дата:** 2026-10-09

**Почему важно.** Свежий релиз основного WebDriver-фреймворка от первоисточника; изменения в основном инкрементальные.

Selenium 4.51.0: поддержка Python 3.15, новый npm-пакет `@seleniumhq/atoms`, генератор BiDi-кода для Java, переход на NUnit v5 в .NET, удалён Guava из Java-биндингов.
