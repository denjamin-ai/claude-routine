# claude-routine — еженедельный дайджест новостей по QA-автоматизации

Репозиторий для автоматического сбора и публикации еженедельного дайджеста новостей
по автоматизации тестирования и QA/SDET-тулингу. Прогон запускает Routine, которая
последовательно вызывает цепочку из трёх скиллов.

## Цепочка скиллов

```
find-news  →  score-news  →  news-report
```

- **find-news** (`.claude/skills/find-news/`) — собирает свежие новости за последнюю
  неделю веб-инструментами Claude Code (WebSearch + WebFetch) широким многозапросным
  проходом. Отдаёт строгий JSON-массив `NewsItem[]`.
- **score-news** (`.claude/skills/score-news/`) — оценивает каждую новость по шкале
  0–10 по пяти взвешенным критериям и отдаёт `ScoredItem[]`, отсортированный по
  убыванию балла.
- **news-report** (`.claude/skills/news-report/`) — верстает из `ScoredItem[]` чистый
  Markdown-дайджест под Obsidian (топ-N + остальное).

Каждый скилл работает и автономно: вход можно подать руками, без предыдущего звена.

## Куда пишутся отчёты

Готовые дайджесты складываются в каталог **`News/`** в формате `News/<YYYY-MM-DD>.md`.
Сам `news-report` отдаёт Markdown в ответ; запись в файл делает агент или Routine.

## Дедуп между прогонами

Файл **`_seen.json`** хранит список уже отражённых URL (JSON-массив строк). Он нужен,
чтобы между прогонами Routine не дублировать новости, попавшие в прошлые дайджесты.
Изначально пустой: `[]`.

## Структура

```
.claude/skills/
  find-news/SKILL.md
  score-news/SKILL.md
  news-report/SKILL.md
News/              # отчёты News/<YYYY-MM-DD>.md
_seen.json         # дедуп между прогонами
```
